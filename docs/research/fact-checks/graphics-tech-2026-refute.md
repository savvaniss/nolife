## Additional findings (relevant to a successor virtual world)

- Steam Sept 2026 tail: "Other" 8.82%, RTX 3050 2.77%, RTX 4060 Laptop 3.35%, RTX 5060 Laptop 2.33%, Steam Deck GPU 0.28%, RTX 5090 0.38%. The modal card is xx60/xx70-class, but a single month's swing (5070 +2.3 pts) means tier targets should use 3-6 month averages, not one survey.
- NTC has a shippable path today: Vulkan CoopVec (driver 570+) and the non-CoopVec DX12 path are cleared to ship; only DX12 LinAlg/SM 6.10 is "do not ship". NTC-on-Load mode gives the 2.5 MB disk/PCIe win while VRAM stays at BCn size, which attacks download size without needing inference-on-sample on weaker GPUs.
- XeSS SR runs on any GPU with SM 6.4/DP4a, and XeSS-FG + XeLL run on non-Intel GPUs: a vendor-neutral frame-generation fallback for the long tail that DLSS (NVIDIA-only) and FSR 4 (RDNA 3/4) do not cover.
- FSR SDK 2.3.0 lists "Vulkan is currently not supported in SDK" as a known issue, which matters if the Tier B client is Vulkan-based (Godot/Linux/Android).
- Chrome on Samsung Xclipse Android GPUs is still "TBD" and Windows ARM64 is behind a flag; Firefox Linux is Nightly-only with a 2026 target. A WebGL2 fallback remains necessary for those cohorts.
- Second Life's viewer is now on a 26.x release train (26.4/26.5 in Oct 2026) with glTF mesh import (2025.05), SLua scripting, "visual polish" and "graphics care package" projects, and a fragment-shader sky/cloud path: SL's renderer is still actively evolving, so the successor's advantage must come from content budgeting and economy design, not only renderer features.
- Ready Player Me's GitHub activity stopped in Aug-Oct 2025 and its core Unity SDK was archived 3 Feb 2026; whatever the exact shutdown date, a hosted third-party avatar API is confirmed as a dead dependency.
